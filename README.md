# 🖼️ Image Captioning AI Project

This project implements an automated image captioning tool using **Gradio** and **IBM Code Engine**. It generates captions for images found on any user-provided webpage. The output is a text file containing all the image URLs along with their respective captions.

---

## 📌 Overview

- 🔍 Automatically captions images from a webpage URL.
- 🧠 Uses AI models via the `transformers` library.
- 🌐 Gradio interface for ease of use.
- 🚀 Deployable on IBM Code Engine.
- 🖼️ Supports various image formats.

---

## File Descriptions

- **automate_url_captioner.py**: This is the main script that automates the process of generating captions for images found on a webpage. It uses Gradio for the user interface and integrates with IBM Code Engine for deployment.

- **hello.py**: A simple script likely used for testing or demonstration purposes. It might contain basic code to verify that the environment is set up correctly or to illustrate a simple concept related to the project.

- **image_cap.py**: Used a BLIP model to generate Image captioning

- **image_captioning_app.py**: Image captioning using gradio model.
  
- **captions.txt**: This output file is generated by the script and contains the URLs of the images along with their corresponding captions.

## 🛠️ Installation

To set up the project locally, follow these steps:

1. **Clone the Repository**
   ```bash
   git clone https://github.com/Subhan-2004/Image_Captioning_AI.git
   cd Image_Captioning_AI
   ```

2. **Create and Activate a Virtual Environment**
   ```bash
   python3 -m venv my_env
   source my_env/bin/activate
   ```

3. **Install Dependencies**

   ```bash
   pip install langchain==0.1.11 gradio==5.23.2 transformers==4.38.2 bs4==0.0.2 requests==2.31.0 torch==2.2.1
   ```

---

## 💻 Usage

1. **Run the Application**
   ```bash
   python3 automate_url_captioner.py
   ```

2. **Provide a URL**  
   Enter the URL of the webpage that contains the images you want to caption.

3. **View Results**  
   A `.txt` file will be generated with image URLs and their AI-generated captions.
